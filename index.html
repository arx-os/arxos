ArxOS

Git for Buildings

Local-first building compiler: field and BIM inputs → validated building.yaml → Git history → IFC interchange.

What this site is

A static landing page only — marketing, status, and documentation pointers. It is not a capture, review, labeling, or Create New client.

Product surfaces (honest)

  • CLI + TUI — primary operator UI (default build)
  • Agent — edge capture node / bridge; durable writes to building.yaml
  • File LiDAR / IFC — current honest spatial + BIM ingest
  • Native iOS companion — future phone LiDAR / RoomPlan path (not shipping yet)

Explicit non-claims

  • No browser LiDAR depth or mesh
  • No ARKit / RoomPlan inside Safari or any pure PWA
  • No “walk-in with the web app” as product capture

Decision: docs/adr/web-demotion.md

Get started

git clone https://github.com/arx-os/arxos.git
cd arxos
git checkout v2.0.0-pilot.5   # preferred L1 pin — see docs/pilot/release.md
cargo install --path . --locked
arx --help

Preferred pin SHA and pilot packet: docs/pilot/release.md · docs/INDEX.md · arxos_manifest.md
